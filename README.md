\# Task Management Dashboard



A simple task management application built with HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.



\## Features

\- Add new tasks

\- View all tasks

\- Edit existing tasks

\- Delete tasks

\- Mark tasks as completed or pending

\- Search tasks

\- Filter tasks by status

\- Sort tasks by priority and due date

\- Store tasks in MongoDB



\## Technologies Used

\- HTML5

\- CSS3

\- JavaScript

\- Node.js

\- Express.js

\- MongoDB

\- Mongoose



\## Backend Setup

1\. Open the backend folder.

2\. Run `npm install`.

3\. Create a `.env` file with your MongoDB connection string and PORT=5000.

4\. Run `node server.js`.



\## Frontend

Open `index.html` using a local development server.
